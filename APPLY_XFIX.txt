SIGMA Engine 0.2.7 network-X memory hotfix

Apply this ZIP over an existing 0.2.7 checkout. The version intentionally remains 0.2.7
so existing completed 0.2.7 checkpoint stages remain reusable.

Changes:
- bounded-memory target-only center-to-center distance extraction for network X
- one shortest-path evaluation per unique source center node within a source type
- durable network-X checkpoint after successful construction
- regression coverage for the old full-distance-cache failure mode

After applying:
  python -m pytest -q
  sigma-engine run <same arguments and same output directory>

Do not use --restart: rerun the same command so clustering/centers/distances/Voronoi checkpoints
can be restored.
